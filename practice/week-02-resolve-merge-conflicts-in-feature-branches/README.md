# Resolve Merge Conflicts in Feature Branches

## Task Brief
Create feature branches, simulate merge conflicts, resolve them manually, and merge to main with clean history.

## Scenario
Your team is integrating parallel feature work; you must detect, resolve, and document conflict resolution.

## Deliverables
- Feature branches with conflicting commits
- Resolved merge with manual conflict fixes
- Commit history showing resolution steps

## Success Criteria
- Conflicts identified and resolved without data loss
- Main branch updated with clean merge commit
- All branches visible in repository history
