# Practice Merging & Add Python Scripts

## Task Brief
Execute merge operations on your repository, then add Python scripts demonstrating variables, data types, and expressions with clean commits.

## Scenario
Your team needs to integrate feature branches and add utility scripts. Merge branches, then commit Python code demonstrating programming fundamentals.

## Deliverables
- Merged feature branches in main
- Python scripts with variables and expressions
- Descriptive commit messages

## Success Criteria
- All feature branches merged to main with clean history
- Python scripts run without errors
- Commits follow atomic commit discipline
