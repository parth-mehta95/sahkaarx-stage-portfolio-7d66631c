# Create Feature Branch and Add Python Script

## Task Brief
Create a feature branch, add Python script demonstrating variables and data types, commit with clear messages, and open pull request for code review.

## Scenario
Your team reviews a new feature branch with Python code before merging to main. Practice the complete PR workflow.

## Deliverables
- Feature branch with Python script
- Pull request with description
- Code review comments addressed

## Success Criteria
- Feature branch created and pushed
- PR opened with clear description
- Python script demonstrates variables and data types
