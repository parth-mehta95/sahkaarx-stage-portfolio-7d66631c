# Set Up Repository Configuration and Basic Commands

## Task Brief
Configure Git repository, create initial commits, and practice essential commands for version control workflow.

## Scenario
Your team needs a properly configured repository with clear commit history and documented setup steps.

## Deliverables
- Configured Git repository with user settings
- Multiple commits demonstrating command usage
- Documentation of setup and commands

## Success Criteria
- Repository initialized with proper configuration
- Commits include meaningful messages
- Basic commands demonstrated (add, commit, push, pull)
