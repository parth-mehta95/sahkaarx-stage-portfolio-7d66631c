# Practice Pull Request and Conflict Resolution Workflow

## Task Brief
Create feature branches, simulate pull requests, and resolve merge conflicts to demonstrate intermediate-level collaborative version control skills.

## Scenario
Your team is reviewing code changes; you must create a PR, handle feedback, and resolve conflicts when merging.

## Deliverables
- Feature branch with commits
- Pull request with description
- Resolved merge conflict example

## Success Criteria
- PR branch created and pushed
- Merge conflict resolved manually
- Clean commit history maintained
